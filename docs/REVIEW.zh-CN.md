## 已知限制

- Docker Compose 配置校验通过；本机 Docker 引擎未运行，容器构建和启动尚未验证。原生 Python＋Neo4j Desktop 路径已实际运行。
- 当前是本地单用户、单 worker 服务，无登录认证，默认只监听本机。
- 研究数量上限为每个来源查询 5,000 条；过大时明确返回 incomplete，不抽样伪装全量。
- 实体与中文名称解释仍可能出错；没有权威术语库和任意医学推理能力。
- 日期范围过滤使用研究开始年份；同研究药物共现不代表同组联合用药，申办方关系也不代表合作。
- 暂无前端、散点图、长期数据清理或两个附加实验。

不需要重新配置已填写的 API key 或重新创建 Neo4j 实例。`.env` 继续只保留在本地。
